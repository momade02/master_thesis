# =============================================================================
# VERSION DRIFT ACROSS THE PIPELINE
#
# The notebooks were not all executed in one session, and two packages moved
# mid-pipeline. Recorded values:
#
#   lightgbm   4.6.0  in NB04 (training), NB05a (scoring)
#              4.7.0  in NB08 (local reliability audit)
#   polars     1.41.2 in NB04
#              1.43.2 in NB05b, NB08, NB09
#
# This file therefore RECONSTRUCTS a single consistent environment rather than
# recording one that existed. Anyone re-running from these pins gets a coherent
# environment, not a byte-identical replay of the original sessions.
#
# FROZEN ARTEFACT: lightgbm is pinned to 4.6.0, the lower of the two, on
# purpose. The frozen booster is both TRAINED (NB04) and used for inference
# (NB05a, `lgb.Booster(model_file=...)`) under 4.6.0, so 4.6.0 is the version
# that guarantees the stored model loads and predicts identically. NB08's 4.7.0
# is used only to fit a throwaway diagnostic model of the miscoverage
# indicator - it never touches the frozen booster - so pinning down to 4.6.0
# costs nothing.
#
#
# ISOTONIC / scikit-learn: WHY THE UNRECORDED PIN MATTERS MOST HERE
#
# sklearn.isotonic.IsotonicRegression produces the PAVA calibration map that
# every downstream result depends on: it is what compresses the upper score
# range toward the ~1% base rate and sets how far above the threshold the
# minority class sits. A different PAVA implementation is a different thesis.
#
# There is a cheap fingerprint for verifying the environment is right. The
# recorded run produced:
#
#   PAVA breakpoints (LightGBM pipeline)  : 516
#   q_hat_SCP                             : 0.01622366
#   q_hat_APS                             : 0.89995086
#   Mondrian FICO x LTV threshold spread   : 128.71x
#   OOS Brier, pre -> post isotonic        : 0.064263 -> 0.008616
#
# If a re-run reproduces 516 breakpoints and q_hat_SCP = 0.01622366, the
# calibration path is faithful regardless of which sklearn version is installed.
# If it does not, the environment differs in a way that matters and nothing
# downstream should be compared to the reported figures.
#
#
